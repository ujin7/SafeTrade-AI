## 역할 정의

이 문서의 "체크리스트"는 **사용자 UI 입력 요소가 아니라 내부 위험 신호 데이터셋**이다.

- LLM(Claude Haiku)이 거래 텍스트를 분석할 때 이 데이터셋을 참조해 해당하는 신호 ID를 추출한다.
- 추출된 ID는 사용자가 검토·수정할 수 있는 형태로 화면에 표시된다.
- 최종 선택된 ID 목록이 규칙 기반 점수 엔진에 전달되어 위험도가 계산된다.

흐름:
```
데이터셋(신호 정의)
    ↓ LLM이 참조
텍스트 → 신호 ID 추출
    ↓ 사용자 검토/수정
최종 신호 목록 → 점수 계산
```
