## 프로젝트 개요
---
### 한 줄 정의
SafeTrade AI — 체크리스트 기반 거래 위험도 MVP

### 제품 목표
사용자가 거래 전 텍스트를 참고로 입력하고 위험 체크리스트를 선택하면 고정 규칙으로 위험도 점수/등급을 계산해 ‘추가 확인’이 필요한지 빠르게 판단하도록 돕는다.

### 배경
중고거래·부동산 거래에서 사기/분쟁은 반복되지만, 초보 사용자는 위험 신호를 체계적으로 점검하기 어렵다. 본 MVP는 AI 판정/연구가 아니라 체크리스트 + 규칙 기반 점수화로 작동 가능성·설명 가능성·일관성을 확보하고, 발표 가능한 결과물을 6주 안에 완성하는 데 초점을 둔다.

### 사용자 문제
- 거래 상대의 말(선입금 요구, 외부 링크 유도 등)이 위험한 신호인지 초보 사용자가 빠르게 판단하기 어렵다.
- 위험 신호가 여러 개 섞이면 ‘지금 거래를 멈추고 무엇을 확인해야 하는지’ 결정하기가 어렵다.
- AI가 단정적으로 판정하는 방식은 오해/과신 위험이 있어, 설명 가능하고 일관된 기준이 필요하다.

### 해결 방안
체크리스트(8~12개)로 사용자가 직접 위험 신호를 선택하게 하고, 서버에서 고정 규칙(신호별 점수)을 합산해 위험도 점수/등급(LOW/MEDIUM/HIGH)을 계산한다. 입력 텍스트는 참고 컨텍스트로만 받으며, 초기 MVP에서는 LLM 없이 일관된 결과를 제공한다. 결과 화면에는 선택된 신호, 간단 설명, 참고용 면책 문구를 함께 제공한다.

### 차별점
- LLM 없이 체크리스트 + 규칙 기반으로 6주 내 완성 가능한 안정적 MVP에 집중
- 같은 입력이면 같은 결과가 나오는 ‘일관된 분석’과 점수 근거가 드러나는 ‘설명 가능성’ 우선
- ‘판정’이 아닌 ‘참고용 점검 도구’ 톤을 고정해 과신/책임 리스크를 줄임

### 타겟 사용자
- 1차: 20~30대 사회초년생(중고거래/임대차 경험이 적고, 빠른 의사결정을 원함)
- 2차: 거래 경험이 적어 위험 신호를 잘 모르는 일반 사용자
- 사용 환경: 모바일 중심, 짧은 시간에 핵심만 확인하려는 성향

사용자 기대
- ‘지금 멈춰야 하는지’가 빠르게 보이길 원함
- 왜 그런 점수가 나왔는지 납득 가능한 설명을 원함

### 사용자 시나리오
1) 사용자는 중고거래 글/대화 또는 부동산 매물·계약 안내 문구를 보다가 의심이 든다.
2) SafeTrade AI에 텍스트를 참고로 붙여넣고(선택), 위험 체크리스트(8~12개)에서 해당되는 항목을 선택한다.
3) 시스템은 선택된 신호를 바탕으로 고정 규칙으로 위험도 점수/등급(LOW/MEDIUM/HIGH)을 계산해 리포트로 보여준다.
4) 사용자는 리포트를 참고해 거래를 보류/중단하거나, 추가 확인 질문/증빙 요청을 진행한다.

주의
- 초기 MVP는 LLM 없이 동작하며, 텍스트 자동 추출/요약은 제공하지 않는다.

### 핵심 지표
MVP 핵심 KPI
- 분석 완료율: 분석 시작 대비 결과 화면 도달 비율
- 체크리스트 완료율: 체크리스트를 끝까지 제출한 비율
- 리포트 유용성(간단 설문): ‘거래 판단에 도움이 됐다’ 응답 비율
- 재방문율(가능하면): 7일 내 재사용 비율

발표/포트폴리오 산출물
- 샘플 시나리오 10개 기준, 동일 입력에서 동일 점수/등급이 나오는 데모 영상/스크린샷
- 위험 신호별 점수표(근거) 1페이지 정리

### 리스크
- 과신/오해 리스크: 점수를 ‘판정’으로 오해할 수 있음 → 참고용/추가 확인 톤, 면책 문구 고정
- 점수 임의성 리스크: 규칙이 납득되지 않으면 불신 → 신호별 점수 근거 간단 설명, 점수표 공개
- 범위 과다 리스크: 텍스트 자동 추출/저장/공유/로그인/크롤링은 MVP에서 제외
- 개인정보 리스크: 입력 텍스트에 민감 정보 포함 가능 → 입력 단계 안내, 결과 화면 전문 재노출 금지(선택 신호만 노출)
- 1인 개발 리스크: UI 디테일/예외 처리 과다 → 핵심 플로우(입력→체크→결과) 우선, 실패/재시도는 단순화
