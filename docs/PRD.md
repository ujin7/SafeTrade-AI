## 프로젝트 개요
---
### 한 줄 정의
SafeTrade AI — LLM 기반 위험 신호 추출 + 규칙 기반 점수화 거래 위험 분석 MVP

### 제품 목표
사용자가 의심스러운 거래 내용을 텍스트로 입력하면, LLM이 위험 신호를 자동으로 추출하고 규칙 기반 점수 엔진이 위험도를 계산해 '거래를 멈추고 무엇을 확인해야 하는지' 빠르게 판단하도록 돕는다.

### 배경
중고거래·부동산 거래에서 사기/분쟁은 반복되지만, 초보 사용자는 위험 신호를 체계적으로 점검하기 어렵다. 기존 체크리스트 방식은 사용자가 이미 위험 신호를 알고 있어야 한다는 전제를 깔고 있어, '사용자는 위험 신호를 체계적으로 판단하기 어렵다'는 문제 정의와 충돌한다. 본 MVP는 LLM을 위험 신호 추출에 활용하되, 최종 판정은 규칙 기반 점수화로 수행해 설명 가능성·일관성을 유지하면서 발표 가능한 결과물을 완성하는 데 초점을 둔다.

### 사용자 문제
- 거래 상대의 말(선입금 요구, 외부 링크 유도 등)이 위험한 신호인지 초보 사용자가 빠르게 판단하기 어렵다.
- 체크리스트를 주면 선택 자체가 어렵다 — "신탁 등기", "전세가율", "가짜 안전결제 URL"의 의미를 모르면 체크할 수 없다.
- 위험 신호가 여러 개 섞이면 '지금 거래를 멈추고 무엇을 확인해야 하는지' 결정하기가 어렵다.
- AI가 단정적으로 판정하는 방식은 오해/과신 위험이 있어, 설명 가능하고 일관된 기준이 필요하다.

### 해결 방안
거래 텍스트(채팅 내용, 매물 설명 등)를 입력하면 LLM(Claude Haiku)이 위험 신호를 자동으로 추출하고, 서버의 규칙 기반 점수 엔진(신호별 고정 점수 합산)이 위험도 점수/등급(LOW/MEDIUM/HIGH)을 계산한다. AI 추출 결과는 사용자가 검토·수정 가능하며, 결과 화면에는 감지된 위험 신호와 원문 근거, 면책 문구를 함께 제공한다.

LLM 역할 경계:
- ✅ 텍스트에서 위험 신호 ID 추출 + 근거 문장 인용
- ❌ 위험 점수 계산 (규칙 엔진이 수행)
- ❌ 사기 여부 판정
- ❌ 법적/금융 판단

### 차별점
- 텍스트만 입력하면 위험 신호를 알지 못해도 분석 가능 (LLM이 신호를 대신 감지)
- LLM 추출 + 규칙 기반 점수화: 같은 입력이면 같은 결과, AI 오류는 사용자가 수정 가능
- '판정'이 아닌 '참고용 점검 도구' 톤을 고정해 과신/책임 리스크를 줄임
- 분석 근거(원문 인용)로 '왜 위험한지' 납득 가능한 설명 제공

### 타겟 사용자
- 1차: 20~30대 사회초년생(중고거래/임대차 경험이 적고, 빠른 의사결정을 원함)
- 2차: 거래 경험이 적어 위험 신호 개념 자체를 모르는 일반 사용자
- 사용 환경: 모바일 중심, 짧은 시간에 핵심만 확인하려는 성향

사용자 기대
- 텍스트만 붙여넣으면 '지금 멈춰야 하는지'가 빠르게 보이길 원함
- 왜 그런 점수가 나왔는지, 어떤 문장이 의심스러운지 납득 가능한 설명을 원함

### 사용자 시나리오
1) 사용자는 중고거래 글/대화 또는 부동산 매물·계약 안내 문구를 보다가 의심이 든다.
2) SafeTrade AI에 텍스트를 붙여넣고 분석을 요청한다.
3) LLM이 텍스트에서 위험 신호를 자동으로 추출한다. 사용자는 AI 결과를 검토하고 필요시 수정한다.
4) 시스템은 최종 신호 목록을 규칙 기반 점수 엔진에 전달해 위험도 점수/등급을 계산한다.
5) 결과 화면에서 점수·등급·감지된 위험 신호·원문 근거를 확인하고, 거래를 보류/중단하거나 추가 확인을 진행한다.

### 핵심 지표
MVP 핵심 KPI
- 분석 완료율: 분석 시작 대비 결과 화면 도달 비율
- AI 추출 수정율: AI가 추출한 신호 중 사용자가 수정(추가/삭제)하는 비율 (AI 품질 간접 지표)
- 리포트 유용성(간단 설문): '거래 판단에 도움이 됐다' 응답 비율
- 재방문율(가능하면): 7일 내 재사용 비율

발표/포트폴리오 산출물
- 샘플 시나리오 10개 기준, 동일 입력에서 동일 점수/등급이 나오는 데모 영상/스크린샷
- LLM 추출 + 규칙 점수 계산 구조 1페이지 다이어그램

### 리스크
- 과신/오해 리스크: 점수를 '판정'으로 오해할 수 있음 → 참고용/추가 확인 톤, 면책 문구 고정
- AI 추출 누락 리스크: LLM이 신호를 놓치면 점수가 낮게 나와 오히려 안심시킬 수 있음 → AI 결과 수정 기능 필수 제공
- AI 추출 오탐 리스크: 없는 신호를 탐지하면 불필요한 불안 유발 → 검토/수정 단계 필수
- 범위 과다 리스크: 텍스트 자동 저장/공유/로그인/크롤링은 MVP에서 제외
- 개인정보 리스크: 입력 텍스트에 민감 정보 포함 가능 → 입력 단계 경고, 결과 화면 근거 표시 시 마스킹
- API 비용 리스크: Claude Haiku 사용으로 비용 최소화, 추출 실패 시 빈 결과로 폴백

### 기술 포지셔닝 (포트폴리오용)
> SafeTrade AI는 LLM을 활용해 거래 텍스트에서 위험 신호를 자동 추출하고, 규칙 기반 점수 엔진으로 설명 가능한 위험도를 계산하는 거래 위험 분석 MVP이다.
